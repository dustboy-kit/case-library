## Make more

```
codex exec --skip-git-repo-check -C /tmp/work \
  "Generate ONE image with your built-in image generation tool. <what> Quiet catalog render, no text, no logos. Reply with only the absolute path of the generated PNG." \
  -i cases/<id>/views/NNN.png
```

- **Put the prompt before `-i`.** `-i` takes several files, so a prompt placed after it is read as a file name, and Codex then exits with "No prompt provided via stdin".
- The PNG is written to `~/.codex/generated_images/<session>/exec-<uuid>.png`. Convert it with `sips -s format jpeg -s formatOptions 72 -Z 1600`.
